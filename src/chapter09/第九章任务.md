## Deep Agents 第 11 章：沙箱执行（Sandbox Execution）学习目标

核心目标：掌握 Deep Agents 沙箱执行机制的工作原理、Backend 接入方式、文件传输、安全隔离与生命周期管理，并能独立实现和验证 Agent 在沙箱中的代码执行。

### 一、重点知识掌握目标

| 学习模块       | 必须掌握的知识                                                               | 掌握标准                                  |
| ---------- | --------------------------------------------------------------------- | ------------------------------------- |
| 1. 沙箱基本原理  | Sandbox 的作用；普通 Backend 与 Sandbox Backend 的区别；`SandboxBackendProtocol` | 能解释 Agent 为什么需要沙箱，以及 `execute()` 如何获得 |
| 2. 沙箱接入机制  | `create_deep_agent()`、`LangSmithSandbox`、`SandboxClient`              | 能独立创建沙箱并连接 Deep Agent                 |
| 3. 代码执行机制  | `execute()`、`ExecuteResponse`、`exit_code`、输出截断                        | 能执行 Shell 命令，识别执行成功、失败及输出截断           |
| 4. 文件传输机制  | `upload_files()`、`download_files()`；宿主与沙箱的文件边界                        | 能将宿主文件上传至沙箱，执行处理后下载结果                 |
| 5. 沙箱安全隔离  | Sandbox as tool、FilesystemPermission、HITL、网络隔离与凭证保护                   | 能区分沙箱隔离、文件权限和工具审批各自负责什么               |
| 6. 沙箱生命周期  | Thread-scoped、Assistant-scoped、TTL、资源回收                               | 能解释不同复用策略，并正确清理沙箱资源                   |
| 7. 沙箱扩展与监控 | Deep Agents Code、SandboxProvider、LangSmith Tracing                    | 理解自定义 Provider 的扩展方式，并能追踪工具执行         |

### 二、必须完成的 5 个实践任务
任务 1：沙箱接入
创建 Deep Agent，连接 Sandbox Backend，在沙箱中执行 Python 命令，打印结果与退出码。

任务 2：文件上传与下载
上传一个 Python 文件至沙箱，运行后下载执行结果，检查文件内容是否一致。

任务 3：异常处理
分别执行正常命令、错误命令和产生大量输出的命令，观察退出码及输出截断机制。

任务 4：安全隔离验证
检查沙箱能否访问宿主文件及环境变量，验证文件权限与 Shell 执行隔离的区别。

任务 5：生命周期与可观测性
复用同一沙箱、查看执行 Trace，并在任务结束后主动回收资源。

### 三、最终能力验收

完成本章后，应能独立回答以下三个问题：

1. 原理层面：Deep Agents 如何通过 Backend 将文件操作和 Shell 执行转移至隔离沙箱？为什么普通 Backend 不等于 Sandbox Backend？
2. 工程层面：如何实现一个完整的沙箱执行过程，包括创建、上传、执行、验证、下载和销毁？
3. 安全层面：为什么使用沙箱并不代表 Agent 自动安全？如何结合网络限制、HITL、凭证隔离与 Tracing 降低风险？

最终达标标准：能够不依赖教程，独立编写一个 Deep Agents 沙箱执行示例，完整演示文件传输、代码执行、错误处理、结果验证与资源回收，并解释其中的关键机制。
